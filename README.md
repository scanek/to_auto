# 🚗 Бортовой Журнал Автомобиля

Современное, быстрое и многофункциональное веб- и мобильное PWA-приложение для ведения электронной сервисной книжки, учета технического обслуживания (ТО), ремонтов, тюнинга, заправок, комплектов шин, страховых полисов, моточасов и детальной аналитики расходов на автомобиль.

Автор: **Александр Щеголев** ([@scanek](https://github.com/scanek))  
Репозиторий: **[https://github.com/scanek/to_auto](https://github.com/scanek/to_auto)**

---

## 🌟 Основные возможности

### 🏢 1. Гараж и карточки автомобилей
* Учет неограниченного количества автомобилей (марка, модель, двигатель, год выпуска, госномер, VIN, фото, текущий пробег и моточасы).
* Спецификации масла (вязкость, допуски, объем картера).
* Выбор индивидуальной валюты (₽, $, €, ₸ и др.) и единиц измерения (км / мили, литры / галлоны).
* Быстрый просмотр ключевых показателей по каждому авто: общий пробег, моточасы, сумма всех расходов и количество актуальных напоминаний к ТО.

---

### 🛡️ 2. Безопасность и защита данных (Режим «Владелец / Гость»)
* **Защита PIN-кодом / паролем**: защита приложения от случайного или несанкционированного редактирования и удаления данных.
* **Режим «Гость» (чтение)**:
  * Безопасный просмотр истории авто, графиков аналитики, заправок, шин и регламентов.
  * Доступен экспорт Сервисной книжки в PDF и выгрузка в Excel.
  * Все кнопки добавления, редактирования и удаления скрыты и заблокированы на уровне API.
* **Режим «Владелец» (полный доступ)**:
  * Вход по PIN-коду с сохранением защищенного токена в браузере.
  * Возможность в 1 клик заблокировать доступ или сменить PIN-код.

---

### 🔧 3. Журнал ТО, Ремонтов и Тюнинга
* **Плановое ТО (Service Records)**: фиксация даты, пробега, моточасов, тега ТО (ТО-0, ТО-1, ТО-2...), стоимости работ и запчастей.
* **Ремонты (Repairs)**: внеплановые работы и устранение неисправностей.
* **Тюнинг и допы (Upgrades)**: учет установки дополнительного оборудования и стайлинга.
* **Детализация запчастей и ссылки на магазины**:
  * Фиксация артикулов (каталожных номеров), брендов и количества.
  * Выбор магазина из готовых пресетов (*Ozon, Wildberries, Exist, Автодок, Emex, Авито, Яндекс Маркет, Официальный дилер*).
  * Прямые кликабельные ссылки на купленные детали в интернет-магазинах.

---

### ⏰ 4. Умный планировщик регламентов и износа
* Гибридные триггеры напоминаний:
  * По **пробегу** (например, каждые 7 500 км).
  * По **моточасам** (например, каждые 250 м/ч).
  * По **времени** (например, каждые 12 месяцев).
  * *Срабатывает по тому условию, которое наступит раньше.*
* Цветовые шкалы износа (прогресс-бары: **В норме** 🟢 -> **Скоро ТО** 🟡 -> **Просрочено** 🔴).
* Кнопка **«Выполнено» в 1 клик** с автоматическим сдвигом следующего интервала.

---

### 🛞 5. Комплекты шин и сезонная переобувка
* Учет летнего, зимнего и всесезонного комплектов резины и дисков.
* Отслеживание остатка глубины протектора в мм и наката в км.
* Место сезонного хранения резины.
* **Переобувка в 1 клик**: мгновенная активация комплекта «☀️ Лето» или «❄️ Зима» с автоматическим подсчетом пробега именно на установленных шинах.

---

### ⛽ 6. Журнал заправок и расход топлива
* Учет заправок по методике «до полного бака».
* Автоматический расчет среднего расхода (л/100 км).
* Расчет цены за 1 литр и итоговой стоимости заправки.
* Учет типа топлива (АИ-95, АИ-100, ДТ) и сети АЗС.

---

### 📑 7. Документы, страховки и сроки
* Учет полисов ОСАГО, КАСКО, диагностических карт техосмотра и других документов.
* Номер полиса, страховая компания, стоимость и заметки.
* Автоматический расчет оставшихся дней до окончания действия с предупреждением об окончании срока.

---

### 📊 8. Аналитика расходов и стоимость 1 км
* **Структура всех расходов**: интерактивная круговая диаграмма по категориям (ТО, Ремонты, Тюнинг, Топливо, Шины, Страховки).
* **Расходы по месяцам**: наглядная гистограмма динамики затрат.
* **Стоимость 1 км пробега**: расчет реальной себестоимости каждого пройденного километра.
* **Средний расход топлива** и статистика заправок.

---

### 📄 9. Экспорт и печать сервисной книжки
* **PDF Сервисная книжка**: профессионально оформленный отчет по всей истории автомобиля со всеми заменами и чеками для печати или передачи новому владельцу при продаже авто.
* **Excel (.xlsx)**: полная структурированная таблица со всеми записями, запчастями и стоимостями.

---

### 📱 10. Мобильное приложение (PWA)
* Устанавливается как полноценное нативное приложение на смартфоны (Android / iOS) и ПК прямо из браузера.
* Работает быстро, плавно и поддерживает офлайн-кэширование через Service Worker.
* Встроенная интерактивная инструкция по установке в 1 клик.

---

### 📥 11. Резервное копирование и восстановление
* Полный экспорт всех данных и журналов в один файл JSON.
* Восстановление базы данных из бэкапа в 1 клик.

## 🚀 Быстрый запуск в Docker (Рекомендуемый способ)

### 1. Клонирование репозитория
```bash
git clone https://github.com/scanek/to_auto.git
cd to_auto
```

### 2. Запуск контейнера
```bash
docker compose up -d --build
```

### 3. Доступ к приложению
* **Веб-приложение:** [http://localhost:9900](http://localhost:9900) *(или IP-адрес вашего сервера / NAS в локальной сети, например `http://192.168.1.2:9900`)*
* **Интерактивная документация REST API (Swagger UI):** [http://localhost:9900/docs](http://localhost:9900/docs)

*Все данные, настройки, токены и загруженные фотографии надежно сохраняются в Docker volume `autotracker_data`.*

## 🔄 Обновление до последней версии

Для обновления работающего контейнера на сервере выполните:

```bash
git fetch origin && git reset --hard origin/main && docker compose build --no-cache && docker compose up -d
```
