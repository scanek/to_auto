# 🚗 AutoTracker (в стиле LubeLogger)

Современное веб-приложение для ведения электронной сервисной книжки, учета технического обслуживания (ТО), ремонтов, заправок, напоминаний и анализа расходов на автомобиль.

Дизайн и функциональность вдохновлены лучшими практиками **[LubeLogger](https://github.com/hargata/lubelogger)**: темная тема, шкалы прогресса ТО, подробная аналитика и мгновенный запуск в Docker.

---

## 🌟 Основные возможности

* **🏢 Гараж (Garage):**
  * Учет нескольких автомобилей (марка, модель, год, госномер, VIN, фото, единицы измерения и валюта).
  * Быстрый просмотр текущего пробега, суммы расходов и активных/просроченных регламентов ТО.

* **🔧 Журнал ТО и ремонтов:**
  * **Плановое ТО (Service Records):** фиксация даты, пробега, стоимости работ и списка запчастей (наименование, артикул, цена, количество).
  * **Ремонты (Repairs):** внеплановое устранение неисправностей.
  * **Тюнинг и допы (Upgrades):** установка дополнительного оборудования и аксессуаров.

* **⛽ Журнал заправок (Fuel Tracking):**
  * Учет расхода топлива по методике «от полного до полного» (л/100 км).
  * Автоматический расчет стоимости за 1 литр и динамики цен на топливо.

* **⏰ План регламентов и напоминания (Maintenance Planner):**
  * Гибридные триггеры: интервалы по **пробегу** (например, 7 500 км) и/или **времени** (например, 12 мес).
  * Визуальные индикаторы износа (прогресс-бары с цветовой индикацией: *Норма* -> *Скоро ТО* -> *Просрочено*).
  * Быстрая кнопка «Отметить выполненным» с обновлением базового пробега и даты.

* **📊 Аналитика и дашборд:**
  * Структура расходов (круговая диаграмма по категориям: ТО, Ремонт, Тюнинг, Топливо).
  * Динамика затрат по месяцам (столбчатый график).
  * График расхода топлива (л/100км).
  * Расчет реальной стоимости 1 километра пробега автомобиля.

* **📑 Электронная сервисная книжка (PDF / Печать):**
  * Генерация профессионального хронологического отчета по автомобилю для печати или сохранения в PDF при продаже авто.

* **📄 Документы и сроки:**
  * Учет полисов ОСАГО / КАСКО, диагностических карт техосмотра, СТС с обратным отсчетом дней до окончания.

## 🚀 Быстрый запуск в Docker (Рекомендуемый способ)

Убедитесь, что у вас установлен **Docker** и **Docker Compose**.

1. Перейдите в папку проекта:
   ```bash
   cd auto-tracker
   ```

2. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```

3. Откройте в браузере:
   * **Веб-приложение:** [http://localhost:8000](http://localhost:8000)
   * **Интерактивная документация API (Swagger UI):** [http://localhost:8000/docs](http://localhost:8000/docs)

*Все данные и загруженные файлы автоматически сохраняются в постоянном Docker volume `autotracker_data`.*

## 💻 Локальный запуск для разработки

### 1. Запуск Backend (FastAPI):
```bash
cd backend
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### 2. Запуск Frontend (React + Vite):
```bash
cd frontend
npm install
npm run dev
```
Фронтенд будет доступен по адресу [http://localhost:3000](http://localhost:3000) с автоматическим проксированием запросов к бэкенду.
