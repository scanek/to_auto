# 🚗 AutoTracker (в стиле LubeLogger)

Современное веб-приложение для ведения электронной сервисной книжки, учета технического обслуживания (ТО), ремонтов, заправок, напоминаний, комплектов шин, моточасов и анализа расходов на автомобиль.

Дизайн и функциональность вдохновлены лучшими практиками **[LubeLogger](https://github.com/hargata/lubelogger)**: темная тема, шкалы прогресса ТО, подробная аналитика, учет моточасов, комплектов шин и мгновенный запуск в Docker.

---

## 🌟 Основные возможности

* **🏢 Гараж (Garage):**
  * Учет автомобилей (марка, модель, двигатель, год, госномер, VIN, фото, моточасы, спецификация масла, валюта).
  * Быстрый просмотр текущего пробега, суммы расходов и активных/просроченных регламентов ТО.

* **🔧 Журнал ТО, Ремонтов и Тюнинга:**
  * **Плановое ТО (Service Records):** фиксация даты, пробега, моточасов, стоимости работ и списка запчастей с артикулами и ссылками на Ozon/маркетплейсы.
  * **Ремонты (Repairs):** внеплановое устранение неисправностей.
  * **Тюнинг и допы (Upgrades):** установка дополнительного оборудования и аксессуаров.

* **🛞 Учет шин и колес (Tyre Sets):**
  * Учет летнего и зимнего комплектов резины.
  * Отслеживание остатка протектора в мм, пробега на комплекте, размерности, места хранения и быстрая смена активного комплекта.

* **⛽ Журнал заправок (Fuel Tracking):**
  * Учет расхода топлива по методике «от полного до полного» (л/100 км).
  * Автоматический расчет стоимости за 1 литр и динамики цен на топливо.

* **⏰ План регламентов и напоминания (Maintenance Planner):**
  * Гибридные триггеры: интервалы по **пробегу** (км), **моточасам** (м/ч) и/или **времени** (мес.) — срабатывает по тому, что наступит раньше.
  * Визуальные индикаторы износа (прогресс-бары: *Норма* -> *Скоро ТО* -> *Просрочено*).
  * Кнопка «Отметить выполненным» в 1 клик с обновлением базовых значений.

* **📊 Аналитика и дашборд:**
  * Структура расходов (круговая диаграмма по категориям: ТО, Ремонт, Тюнинг, Топливо).
  * Динамика затрат по месяцам (столбчатый график).
  * График расхода топлива (л/100км).
  * Расчет реальной стоимости 1 километра пробега автомобиля.

* **📑 Электронная сервисная книжка (PDF / Печать):**
  * Генерация профессионального хронологического отчета по автомобилю для печати или сохранения в PDF при продаже авто.

* **📥 Импорт и экспорт бэкапа:**
  * Восстановление полной истории в 1 клик из файлов `car-maintenance-app` (v2.5) или AutoTracker.

## 🚀 Быстрый запуск в Docker (Рекомендуемый способ)

1. Перейдите в папку проекта:
   ```bash
   cd to_auto
   ```

2. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```

3. Откройте в браузере:
   * **Веб-приложение:** [http://localhost:9900](http://localhost:9900)
   * **Интерактивная документация API (Swagger UI):** [http://localhost:9900/docs](http://localhost:9900/docs)

*Все данные и загруженные файлы автоматически сохраняются в постоянном Docker volume `autotracker_data`.*
