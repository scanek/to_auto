# 🚗 Бортовой Журнал Автомобиля (AutoTracker)

## 💡 О проекте

Проект создавался «для себя» и для автолюбителей-одноклубников. Я не являюсь профессиональным разработчиком ПО, поэтому делал приложение от души, стараясь решить наболевшие вопросы: ведение удобной сервисной книжки, учет заправок, чеков, остатка бензина и пробега через сигнализацию StarLine, а также быстрый доступ к заводским схемам и инструкциям прямо со смартфона возле машины.

Приложение **полностью бесплатное для личного использования**, работает в любом браузере, устанавливается как приложение на телефон (PWA) и способно работать автономно даже при отсутствии интернета в подземном паркинге или в дороге.

Все заводские схемы, руководства и регламенты Changan CS55 Plus собраны и оцифрованы из открытых источников для удобства одноклубников.

## 🌟 Ключевые возможности программы

### 🎛️ 1. Конструктор интерфейса и настройка видимости вкладок (Новинка v3.5.0)
* **Индивидуальная настройка каждого автомобиля**: в окне настроек машины можно в один клик включить или отключить любую из 8 вкладок:
  1. 🔧 **ТО и работы** (сервисный журнал, ремонты, тюнинг)
  2. ⛽ **Топливо** (журнал заправок и расход)
  3. 📅 **Регламент** (напоминания и график ТО)
  4. 📊 **Аналитика** (графики затрат и стоимость 1 км)
  5. 📖 **Расходники** (артикулы запчастей и допуски)
  6. 🛞 **Шины** (комплекты, остаток протектора, ротация)
  7. 📄 **Документы** (ОСАГО, КАСКО, СТС, права)
  8. ⚡ **База знаний** (электросхемы, предохранители, калибровки, DTC)
* **Идеально для смартфонов**: при отключении ненужных вкладок полоса навигации аккуратно умещается на одном экране без горизонтального скролла.
* **Быстрые пресеты**: *«Все»*, *«Без Wiki»* (для авто других марок), *«ТО + АЗС»* (ультра-минималистичный блокнот).

---

### ⚡ 2. Эксклюзивная База Знаний Changan CS55 Plus (Оцифровка 1 719 стр. мануала)
* **🗺️ Атлас 674 электрических схем высокого разрешения**:
  * Все заводские схемы оцифрованы и сконвертированы в ультра-быстрый формат WebP.
  * Каталог по 11 системам: ЭБУ двигателя Blue Whale 1.5T, коробка 7DCT, системы ABS/ESP/EPB, подушки безопасности, адаптивный круиз ACC, камеры 360°, бесключевой доступ PEPS, климат-контроль, аудиосистема и внешнее освещение.
  * Интерактивный зум (приближение, колесико мыши, жесты пальцами на телефоне).
  * Центр загрузки: скачивание оригинального мануала (32 МБ) и полного оффлайн-архива схем (50.6 МБ).
* **⚡ Предохранители и реле с интерактивной подсветкой**:
  * 3 блока предохранителей (Салон B01, Под капотом C09, Силовой на клемме АКБ C08) — 92 цепи.
  * Разметка типов питания: `BAT+ (12V постоянное)`, `ACC (аксессуары)`, `IG1 (зажигание)`. Идеально для безопасного подключения видеорегистраторов с режимом парковки (Hardwire Kit) и радар-детекторов.
* **⚙️ Сервисные калибровки, адаптации и сбросы**:
  1. *Сброс ключа ТО вручную* (без сканера, через кнопки мультируля).
  2. *Адаптация сцеплений и клапанов 7DCT* (устранение пинков, калибровка после смены масла).
  3. *Сервисный режим стояночного тормоза (EPB)* (программный и аварийный механический отвод суппортов для замены задних колодок).
  4. *Калибровка датчика угла поворота руля (SAS)* (обучение нуля после сход-развала).
  5. *Обучение автодоводчиков стеклоподъемников и люка* (инициализация антизащемления после сброса клеммы АКБ).
  6. *Привязка датчиков давления в шинах (TPMS)* (калибровка 433 МГц после переобувки).
  7. *Аварийный перевод 7DCT в нейтраль (N)* (механическая разблокировка селектора при севшем аккумуляторе для эвакуатора).
* **⚡ Заводская сервисная сетка ТО Changan в 1 клик**:
  * Автоматическое создание 7 заводских регламентов с оригинальными артикулами OEM и допусками: масло 0W-20 SP (10 000 км / 12 мес), фильтр PM2.5, воздушный фильтр, тормозная жидкость DOT 4 Class 6, иридиевые свечи, масло 7DCT, антифриз G12+.
* **⚠️ Сканер 1 391 кода неисправностей (DTC)**:
  * Стандартные OBD-II (SAE J2012) + дилерские коды Changan (`P0`, `P1`, `P2`, `U0`, `U1`, `C0`, `B0`).
  * Поиск по коду или симптому на русском языке, расшифровка систем и вероятные причины.
* **📑 Навигатор по 1 719 страницам мануала**:
  * Оглавление из 11 глав и 40+ подразделов с прямым переходом по номерам страниц `#page=XXX` в браузере.

### 📡 3. Телематика StarLine S96 (CAN / OBD)
* **Прямая интеграция по API StarLine**:
  * Отображение текущего остатка топлива в баке в литрах и процентах.
  * Напряжение аккумулятора (с цветовой индикацией заряда).
  * Температура двигателя и температура в салоне.
  * Статус охраны, заведен/заглушен двигатель, ручной тормоз, статус дверей и багажника.
  * Баланс SIM-карты, качество GSM-сигнала и тип позиционирования (GPS/ГЛОНАСС).
  * Автоматическая фоновая синхронизация с настраиваемым интервалом (от 30 мин до 24 ч).

---

### 📱 4. QR-сервисная книжка и наклейка под капот
* **Электронная сервисная книжка по QR-коду**: персональный QR-код для каждого авто. При сканировании камерой смартфона открывается чистая сервисная история авто без регистрации (идеально при продаже авто на Авито / Авто.ру).
* **Подкапотная бирка ТО для печати**:
  * Автоматический расчет следующей замены масла и фильтров по регламенту.
  * Форматы: представительская сервисная карта или компактная наклейка 90×50 мм для самоклеек.

---

### 📊 5. Финансы, Аналитика и Учет
* Расчет себестоимости владения автомобилем (рублей за 1 км).
* Детальный учет топлива (средний расход на 100 км, графики изменения расхода, динамика цен на бензин).
* Учет комплектов шин (глубина протектора в мм, остаточный ресурс, сезонность, схема ротации колес).
* Хранение документов (ОСАГО, КАСКО, СТС, водительское удостоверение) с уведомлением об окончании срока действия.
* Экспорт всех данных в **Excel (.xlsx)** и генерация красивого PDF-отчета.

## 🚀 Быстрый запуск в Docker (1 команда)

### 1. Клонирование репозитория
```bash
git clone https://github.com/scanek/to_auto.git
cd to_auto
```

### 2. Запуск контейнера
```bash
docker compose up -d --build
```

### 3. Открытие приложения
* **Веб-приложение:** [http://localhost:9900](http://localhost:9900) *(или IP вашего сервера/NAS)*
* **Интерактивная документация API (Swagger):** [http://localhost:9900/docs](http://localhost:9900/docs)

*Все данные пользователей, база данных и загруженные чеки сохраняются в именованный Docker volume `autotracker_data`.*

## 🔄 Как обновиться на сервере до последней версии

Для обновления работающего контейнера на сервере выполните:

```bash
git fetch origin && git reset --hard origin/main && docker compose build --no-cache && docker compose up -d
```
